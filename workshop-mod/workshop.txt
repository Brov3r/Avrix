description=[h2] ℹ️ About [/h2]
description=Avrix is a modern Java mod loader and mixin framework for Project Zomboid. It runs Java plugins from mods without repacking the game: it swaps the game classloader, applies ASM mixins, reads [i]metadata.yml[/i], and invokes plugin entrypoints. Requires [b]Java 25[/b], which is bundled with Project Zomboid Build 42.
description=

description=[h2] ❓ FAQ [/h2]
description=
description=[b]Q: How do I load Java plugins?[/b]
description=A: Put plugin JARs into the plugins folder, or distribute them through a Workshop mod using the [i]jarPlugins[/i] key in mod.info. Avrix loads jarPlugins only from active mods.
description=
description=[b]Q: Does Avrix work in multiplayer?[/b]
description=A: Yes. Avrix supports both the graphical client and the dedicated server, so it works in multiplayer. Install and configure it on the server, and on clients too if the plugin has a client-side part.
description=
description=[b]Q: Does Avrix work with ZombieBuddy?[/b]
description=A: Not recommended. Do not run Avrix and ZombieBuddy on the same game launch — both frameworks transform game classes, and combining them can cause hard-to-diagnose conflicts.
description=
description=[b]Q: Why use Avrix if ZombieBuddy already exists?[/b]
description=A: Avrix is a full plugin loader with Workshop distribution, plugin metadata, dependency resolution, load order, lifecycle/services and Sponge-style mixins. ZombieBuddy is a ByteBuddy patch framework; its patches need porting to Avrix. Pick one — do not run both at once.
description=
description=[b]Q: How do I disable a plugin without deleting it?[/b]
description=A: Create [i]plugins/disabled.txt[/i] and list one plugin ID or JAR name per line. Lines starting with # are ignored.
description=
description=[b]Q: Is Avrix open source?[/b]
description=A: Yes. Avrix is licensed under the MIT License.
