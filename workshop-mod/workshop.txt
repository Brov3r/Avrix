description=ABOUT
description=Avrix is a modern Java mod loader and mixin framework for Project Zomboid. It runs Java plugins from mods without repacking the game: it swaps the game classloader, applies ASM mixins, reads metadata.yml, and invokes plugin entrypoints. Requires Java 25, which is bundled with Project Zomboid Build 42.
