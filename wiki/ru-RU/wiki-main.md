# 📄 Документация

Данная документация актуальна для следующих версий:

- 🧟 **Project Zomboid:** `42.21.0+`
- ⚡ **Avrix Loader:** актуальный релиз (см. [Releases](https://github.com/Brov3r/Avrix/releases))
- ☕ **Java Runtime:** `JDK 25+`

> [!IMPORTANT]
> Для разработки плагинов и запуска вручную через `java -jar` требуется **Java Development Kit (JDK) версии 25 или
> выше**. Более старые версии Java не поддерживаются. Пользователи Steam Workshop используют Java 25, встроенную в
> Project Zomboid, и отдельный JDK им не нужен.

---

### 🤓 Терминология

В документации используются следующие ключевые понятия:

- **Плагин (Plugin / Mod):** Пользовательский программный модуль в формате `.jar`, содержащий логику, ресурсы или
  миксины для расширения функционала игры.
- **Миксин (Mixin):** Механизм динамической модификации байт-кода классов игры (Project Zomboid) на лету при их загрузке
  в JVM без изменения оригинальных файлов игры.
- **KnotClassLoader:** Трансформирующий загрузчик классов, объединяющий классы игры, загрузчика и плагинов в одном
  плоском домене. Внутренности JVM, логирование и библиотеки самого загрузчика делегируются родительскому загрузчику.
- **ServiceManager:** Встроенный типобезопасный реестр сервисов (Service Locator), связывающий контракты интерфейсов с
  их реализациями в рантайме.
- **Workshop-мод:** Мод Project Zomboid, распространяемый через Steam Workshop. Workshop-мод может объявлять
  Java-плагины Avrix через ключ `jarPlugins` в `mod.info`.
