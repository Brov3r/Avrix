## 🎈 События

На данный момент в Project Zomboid существует около 200 стандартных Lua событий, на которые можно подписаться и в Java
плагинах. По мере разработки API будут добавляться и пользовательские события, необходимые для расширения функциональных
возможностей.

Посмотреть все существующие классы событий
можно [здесь](https://github.com/Brov3r/Avrix/tree/main/avrix-api/src/main/java/com/avrix/api/events).

### 🧩 Создание класса-обработчика события

Чтобы начать работать с каким-либо событием, необходимо создать обработчик, который будет обрабатывать каждый вызов
конкретного события.

Все события расширяют базовый абстрактный класс `Event` и переопределяются метод `String getEventName()`, который
позволяет получить название конкретного события.

Пример обработки события `OnGameBoot`:

```java
import com.avrix.api.events.OnGameBootEvent;

/**
 * Класс обработчика события. Он обязательно расширяет абстрактный класс события (в данном случае OnGameBootEvent)
 */
public class OnGameBootHandler extends OnGameBootEvent {
    /**
     * Метод обработки события. Он вызывается каждый раз, когда происходит событие.
     * Например, OnGameBootEvent - cрабатывает при запуске игры или сервера, либо когда моды перезагружаются во время игры.
     *
     * В других событиях метод 'handle' может принимать различные аргументы,
     * в исключительных случаях может существовать несколько таких методов (с разными аргументами)
     */
    @Override
    public void handle() {
        // ...
    }
}
```

### 🛫 Регистрация обработки события

Каждый обработчик события должен быть зарегистрирован в `EventManager`, в противном случае он не будет вызываться:

```java
import com.avrix.core.Metadata;
import com.avrix.plugins.Plugin;
import com.avrix.api.events.EventManager;

// ... другие импорты

/**
 * Точка входа плагина, которая обязательно расширяет абстрактный класс Plugin
 */
public class ExamplePlugin extends Plugin {
    /**
     * Конструктор плагина, все аргументы передаются динамически, в ручную указывать ничего не нужно
     *
     * @param metadata   метаданные плагина
     * @param pluginFile файл плагина (файл .jar архива)
     * @param iconURI    URI иконки плагина. Может быть null, если в архиве плагина нет иконки или возникли какие-то проблемы.
     */
    public ExamplePlugin(Metadata metadata, File pluginFile, URI iconURI) {
        super(metadata, pluginFile, iconURI);
    }

    /**
     * Событие инициализации плагина. Основная логика реализуется именно здесь. 
     * Используется для подписки на события, регистрации команд и прочего.
     * Вызывается до старта игры/сервера
     */
    @Override
    public void onInitialize() {
        // Регистрация события с приоритетом 0 (по-умолчанию). 
        // Чем выше приоритет, тем раньше будет вызван обработчик среди прочих для данного события.

        EventManager.addListener(new OnGameBootHandler());
        // EventManager.addListener(new OnGameBootHandler(), 1000); // Регистрация с приоритетом 1000
    }
}
```

### 🧟 Создание и вызов пользовательских событий

Вы можете создать любое пользовательское событие и оно будет автоматически передано и в окружение Lua:

```java
// импорты

/**
 * Точка входа плагина, которая обязательно расширяет абстрактный класс Plugin
 */
public class ExamplePlugin extends Plugin {
    /**
     * Конструктор плагина, все аргументы передаются динамически, в ручную указывать ничего не нужно
     *
     * @param metadata   метаданные плагина
     * @param pluginFile файл плагина (файл .jar архива)
     * @param iconURI    URI иконки плагина. Может быть null, если в архиве плагина нет иконки или возникли какие-то проблемы.
     */
    public ExamplePlugin(Metadata metadata, File pluginFile, URI iconURI) {
        super(metadata, pluginFile, iconURI);
    }

    /**
     * Событие инициализации плагина. Основная логика реализуется именно здесь. 
     * Используется для подписки на события, регистрации команд и прочего.
     * Вызывается до старта игры/сервера
     */
    @Override
    public void onInitialize() {
        EventManager.addCustomEvent(
                "EventCustom", // Название должно быть в стиле "PascalCase", без использования спец. символов и не латинских символов. В противном случае оно будет нормализовано (удалены спец. символы, нижнее подчеркивания, тире, пробелы и т.п, изменен регистр)
                List.of(ExampleTest.class), // Список пользовательских классов, которые будут экспонированы в Lua, реализующих интерфейс `ExposedToLua`
                List.of(new ExampleObjectTest()) // Список глобальных объектов, содержащий методы, которые будут экспонированы в Lua, с интерфейсом `@LuaMethod`
        );

        // После регистрации вы можете вызывать это событие в любом месте и передавать не более 8 аргументов (текущее ограничение PZ) 
        // EventManager.invokeCustomEvent("EventCustom", args);
    }
}
```

Пример в Lua:

```lua
local function EventCustom()
    -- Твой код здесь
end

Events.EventCustom.Add(EventCustom)
```

Для того чтобы использовать пользовательское событие в Java, рекомендуем создать абстрактный класс:

```java
/**
 * Описание событие
 */
public abstract class CustomEvent extends Event {
    /**
     * Getting the event name
     *
     * @return name of the event being implemented
     */
    @Override
    public String getEventName() {
        return "EventCustom"; // Указывается название вашего события
    }

    /**
     * Called Event Handling Method
     */
    public abstract void handle(); // Либо с аргументами, если они есть
}
```

Потом вы сможете создать обработчик и использовать его, как указано [выше](#-создание-класса-обработчика-события)
